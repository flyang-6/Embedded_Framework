# 嵌入式 C++ 框架开发实战全记录 (Journey Log)

## 第一阶段：概念启蒙与项目初始化 (Day 1)

### Q1: `Embedded_Framework` 是什么意思？为什么要建这个仓库？
- **解答**：意为“嵌入式框架”。现代嵌入式开发不再是所有代码塞进 `main.c`，而是需要分层解耦。建仓库是为了满足工程要求，记录完整的 Git Commit 提交历史，展示开发过程。

### Q2: Git 的“三板斧”是什么？为什么要一直敲？
- **解答**：`git add .`（打包）、`git commit -m "备注"`（本地存档）、`git push`（上传云端）。
- **意义**：不要攒到最后一天才提交。每完成一个小模块（如写完 Logger、点亮灯）就提交一次，能让你的提交记录极其漂亮，且代码写崩了随时可以回滚。

### Q3: 为什么代码里总是出现 `extern "C"`？
- **解答**：C++ 编译器会对函数名进行“名称修饰”（Name Mangling），而 C 语言（如 `main.c`）不认识。加 `extern "C"` 就是告诉编译器：“这个函数请按 C 语言的规矩编译”，实现 C/C++ 混编。

## 第二阶段：基础组件搭建与 PC 端测试 (Day 2-3)

### Q4: `ErrorCode.hpp` 里的 `enum class` 是什么？
- **解答**：C++11 的强类型枚举。比 C 语言的 `enum` 更安全，必须带上作用域前缀（如 `ErrorCode::ERR_TIMEOUT`），防止命名冲突。

### Q5: `Logger` 日志模块是怎么实现的？
- **解答**：使用 `printf` 进行格式化打印（格式为 `[级别][标签] 消息`）。**注意**：在 PC 端测通后，后续必须底层重定向到串口，才能在单片机串口助手上看到日志。

### Q6: `g++` 编译命令那么长，是什么意思？
- **解答**：`g++ test_main.cpp Logger.cpp -o test.exe -I Common -std=c++17`。翻译过来就是：用 C++17 标准，去 `Common` 文件夹里找头文件，把这两个 `.cpp` 编译成 `test.exe`。

## 第三阶段：CMake 工程重构与 Git 排坑 (Day 4)

### Q7: `CMakeLists.txt` 是干嘛的？为什么总是报错找不到文件？
- **解答**：CMake 是工程大管家，负责告诉编译器去哪里找代码。
- **踩坑**：路径千万别敲错！文件夹和文件之间必须是斜杠 `/`（如 `Common/UartTask.cpp`），手滑敲成句号 `.` 或敲错字母（如 `Coommon`）都会导致编译直接 `FATALED`。

### Q8: 为什么用 `git push` 老是遇到 `Connection was reset`？
- **解答**：国内连 GitHub 网络抽风。最快的懒人解决办法是：按键盘的 `↑`（向上箭头）调出历史命令，疯狂按回车重试。或者下载 Watt Toolkit 开加速。

## 第四阶段：真机硬件与 FreeRTOS 打通 (Day 5)

### Q9: 为什么要在 CubeMX 里配置 DMA 和空闲中断 (IDLE)？
- **解答**：这是高性能串口收发的黄金组合。DMA 负责悄悄把数据搬运到内存（不占 CPU）；空闲中断负责在数据发送完毕后通知 CPU“这包收齐了”。两者结合，完美避免了 CPU 傻等（阻塞）和频繁进中断导致的死机。

### Q10: 什么是纯虚接口 (`IUart`) 和“合同”？
- **解答**：像 `virtual ErrorCode Init(...) = 0;` 就是纯虚函数。它只规定“必须有这个功能”，但不写具体实现。具体的活儿交给 `Stm32Uart`（继承类）去干。好处是：以后换芯片，业务代码一行都不用改。

### Q11: 什么是 `UartTask`？为什么要用队列？
- **解答**：`UartTask` 是一个 FreeRTOS 任务。中断里绝对不能做耗时操作，所以中断只负责把数据塞进“队列”（快递柜），然后任务（`UartTask`）在后台慢慢取件处理，这样系统才不会卡死。

### Q12: 为什么灯一直不闪？
- **解答**：
  1. 没在 CubeMX 里把 `PC13` 设为 `GPIO_Output`。
  2. 中断回调被 CubeMX 重新生成时覆盖了。
  3. 函数名大小写敲错（`start` 和 `Start`）导致编译失败。

## 第五阶段：调试与验证

### Q13: `SSCOM` 和串口助手是干嘛的？
- **解答**：电脑上用来接收和发送串口数据的软件。发送 64 个字符，单片机收到后触发中断，将数据塞进队列，`UartTask` 收到后通过 `uart_port_->Transmit()` 原样发回（回显测试）。

### Q14: 为什么蓝灯一直常亮（或者一秒闪一下）？
- **解答**：
  - 常亮：可能是硬件配置错误，或者程序卡死在了别的地方。
  - 规律闪烁：那是你在 `Run()` 函数的 `else`（超时处理）里写的心跳灯代码在正常工作，说明系统还活着。

## 总结与反思
经过这几天的开发，这套框架已经具备了工业级的雏形：
1. **接口抽象**：彻底解耦了硬件层与业务层。
2. **异常处理**：通过 `ErrorCode` 杜绝了静默失败。
3. **并发模型**：利用 FreeRTOS 队列 + DMA + 中断，实现了高效的数据吞吐。
